## Reestar Website

This is the Reestar website, built using HTML and CSS. It's a modern and responsive website designed to showcase the features and services of Reestar. The website provides an intuitive and visually appealing layout with a focus on user experience.

## Features

 - Responsive Design: Ensures the website looks great on all screen sizes, including desktop, tablet, and mobile.
 - Home Page: Introduces Reestar with a clean design and a quick overview of what the site is about.
 - Services/Features Section: Highlights the key services and features provided by Reestar, with easy navigation.
 - Contact Page: Allows users to get in touch through a contact form or find contact details.
   
## Technologies Used

 - HTML5
 - CSS3
